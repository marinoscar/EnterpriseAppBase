Full-bleed pages and a context pane for the app shell (#1080). `ShellLayout` gains `mainVariant` (`'padded'` default, or `'full-bleed'`), and `@marinoscar/platform-web/shell/headless` and `/shell/ui` export `useShellMainVariant(variant)` so a page (a map, a full-screen viewer) asks for full bleed while it is mounted without remounting the shell: `<main>` drops its side and top padding and the `banners` slot, and keeps the bottom-bar clearance below `sm` (gate 3 unchanged). `ShellDestination` gains `contextPane` (`ComponentType<ShellContextPaneProps>`, with the types `ShellContextPane`, `ShellContextPaneProps` and the constant `CONTEXT_PANE_WIDTH` = 240): `ShellNavigationRail` draws it as an `<aside>` beside the expanded rail while that destination is active, reusing the rail's own `expanded` state (hidden at the medium rail, when collapsed, in Console mode and below `sm`), and it stays mounted across route changes inside the destination. `@marinoscar/platform-web/shell/testing` also registers the `shell-layout-variants` web conformance suite (no options). Additive: the defaults render what they did, except that `<main>` now carries `data-main-variant`; the five breakpoint gates did not move.
