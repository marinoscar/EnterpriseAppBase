OAuth server: resource-server helpers (PP-15.6). Protected resource metadata (RFC 9728) at `GET /api/oauth/.well-known/protected-resource[/<resource path>]` (`resource` is `APP_URL` plus the path, one authorization server; the bare path answers when exactly one resource is registered). `buildBearerChallenge` builds the `WWW-Authenticate: Bearer resource_metadata="..."` value with quoting and no line breaks. `JwtAuthGuard` adds that challenge to every `401` on a protected resource's routes (no credential, a bad session or PAT, an invalid or expired `oat_` token; `error="invalid_token"` only when a credential was presented); routes outside every resource and a disabled server keep their `401` exactly. `InsufficientScopeException` and `assertOAuthScopes(principal, resourceId, scopes)` answer `403` with `error="insufficient_scope"` and the granted scopes together with the missing ones; `PermissionsGuard` maps a denial of an `oauth` principal to it when the user holds the permission and a scope of the resource grants it, else a plain `403`. New in `@marinoscar/platform-api/core`: `withResponseHeaders` / `responseHeadersOf` (an exception can ask the error filter for response headers). New in `@marinoscar/platform-api/host`: `buildCorsOptions(raw, { openPaths })` (prefixes that answer any origin without credentials, through the plugin's per-request delegate; every other route keeps the policy), and `OAUTH_PUBLIC_CORS_PATHS` in `@marinoscar/platform-api/identity` for the token, register and revoke endpoints and the metadata documents. Pass it from `main.ts` when `CORS_ORIGIN` lists an allowlist. `@marinoscar/platform-infra` ships `nginx/platform/oauth-server.conf` (`/.well-known/oauth-authorization-server` and `/.well-known/oauth-protected-resource[/<path>]` to the API, `/.well-known/openid-configuration` and other unknown `/.well-known/oauth-*` paths as a JSON `404`, never the SPA); an app opts in with `include /etc/nginx/platform/oauth-server.conf;` in `infra/nginx/app.d/locations/oauth-server.conf`. Run `platform-infra sync` after upgrading.
