Add opt-in provider-credential delivery to worker nodes, server half (#1083). OFF by default and gated pending a platform rule amendment (proposed in `docs/specs/worker-nodes.md`): with the defaults no provider key leaves the server, every `ai.*` type stays server-only and kvox/EvoPath behaviour is unchanged. A job handler declares `nodeCredentialPurposes`; purposes are an open registry (`registerNodeCredentialPurpose`, ids `<namespace>:<name>`), and the AI slice registers `ai:<providerId>` for each configured provider (organization or deployment key only, never a user's BYOK key). The `nodes` settings namespace gains `credentialDelivery` (`enabled`, `cacheTtlMinutes` 5-240, `purposes` allowlist, server-written `epoch`); `NodeOffloadService` withholds a declaring type unless every purpose is deliverable. `POST /api/nodes/:id/credentials/:purpose` issues the credential for a held, declaring job (refusals 409 `CREDENTIAL_DELIVERY_DISABLED`, 404 `UNKNOWN_PURPOSE`, 409 lease, 403 `PURPOSE_NOT_DECLARED`, 429, 424 `CREDENTIAL_UNAVAILABLE`), with a non-secret HMAC `version`, the TTL expiry and the epoch; heartbeat and claim responses carry `credentialDelivery`, `serverFeatures` gains `node_credential_delivery`, and `POST /api/admin/nodes/credential-delivery/revoke-all` (`system_settings:write`) advances the epoch. Platform migration `0043_add_node_credential_issuances` adds the audit table (no material column; purged after 30 days by `nodes.credential_issuances_purge`); every issuance also writes an `audit_events` row `node_credential:issued` with purpose and version only. Also: `registerAiFeature({ nodeCredentialDelivery })`, the `app.nodes.credentials.issued` counter, the `node.credential.issue` span, the Doctor check `nodes.credential_delivery`, the `node-credential-cache` conformance suite (API half), amended `ai-jobs-server-only` and `ai-secret-egress` suites, `:id/credentials/*` reserved on the node plane, relayed span attributes named like a secret refused, and an absent optional settings field now reads as the namespace default. The CLI node cache follows separately.
