Identity: the OAuth server's resource-server half (PP-15.3, epic #1178; docs/specs/oauth-server.md). `IdentityModule.forRoot({ oauthServer: {} })` mounts it; without the option nothing changes. New: the open registries `registerOAuthScope` (with the built-in `offline_access`) and `registerOAuthProtectedResource` (route prefixes, never `/api/oauth`, `/api/auth` or `/api/nodes`, never shared or nested; a scope naming an unregistered permission is a boot error), the credential kind `oauth` (`BuiltinCredentialKind`, `CredentialKinds`, `UserPrincipal.credential` and `AuthCredentialInfo` gain it), `OAuthTokenResolver`, `principal.oauth` and `@OAuthGrant()`, and `InProcessDelegation` (`headerFor`, `inject`: a short-lived in-memory `ipd_` credential a protected resource uses to call the app's own routes as the caller, unusable from the network and after its request ended). `JwtAuthGuard` gains an additive `Bearer oat_` branch (feature gate, route confinement before any I/O with the same prefix helper as `nod_`, audience binding, one 401 message for every token refusal) and a `Bearer ipd_` branch; the permission narrowing (the user's permissions intersected with the scopes' permissions) is written once, in `resolveEffectiveAccess`, on the request's copy of the graph and never in the principal cache. `RolesGuard` never admits an `oauth` credential on a route guarded by `@Roles()` alone. PAT creation and revocation, device approval and revocation and `logout-all` refuse an `oauth` credential, as `switchOrg` always refused anything but a session; `@NodeRoute()` lists no `oauth` credential. New system settings namespace `oauthServer` (full field list; ships off) declared by the settings slice and registered by `SettingsModule.forRoot()` when the server is mounted; `IDENTITY_OAUTH_SETTINGS` is the port identity reads it through (cached 5 s; unbound, the server reads as off). Existing credentials are unaffected: a session JWT, a `pat_` and a `nod_` take exactly the paths they took before, and `JwtAuthGuard`'s new constructor parameters are optional.
