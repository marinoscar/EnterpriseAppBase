Identity: the OAuth server's web side (PP-15.7). `/identity/ui` gains `OAuthConsentPage` (`/oauth/consent`: the client's host leads, the self-asserted name and logo second, the return host, a loopback warning, a first-time notice, scopes grouped by risk with `elevated` and `high` unticked, `Allow` disabled for one second and while submitting, slots `Header`, `Footer` and `scopeIcon`), `OAuthErrorPage` (`/oauth/error`, the closed code list, nothing echoed from the query), `ConnectedAppsPage` (`/settings/connected-apps`, disconnect with a confirmation) and `OAuthClientsPage` (`/admin/settings/oauth-clients`: the switch and issuer, the allowed client hosts with suggestions and refused hosts, the client list with add, disable, rotate and delete, the token lifetimes). New opt-in registry keys `identityAdminSections.oauthClients` (`oauth_clients:read`, no feature) and `identityUserSettingsSections.connectedApps` (no permission, `feature: 'oauthServer'`); existing keys are unchanged. `/identity/headless` gains `createOAuthServerApi`, `useOAuthServerApi`, `OAuthServerStatusProvider`, `useOAuthServerStatus`, `useOAuthServerFeature` and the hooks `useOAuthRequest`, `useOAuthGrants`, `useOAuthClients`, `useOAuthRefusedHosts` and `useOAuthServerSettings`; `IdentityWebAdapters` gains an optional `oauthApi`. The settings slice declares the `oauthServer` key in `SettingsFeatureRegistry`.
